Coinbase Exchange public market data

The watchlist uses public statistics for BTC-USD, ETH-USD, SOL-USD, LINK-USD, DOGE-USD, and USDT-USD. No exchange account, API key, wallet, or private transaction feed is connected.

Statistics are venue-specific, not a consolidated view of the market. API volume is measured in base-asset units. Last price may differ from prices on other venues.

GET https://api.exchange.coinbase.com/products/{ASSET}-USD/stats
GET https://api.exchange.coinbase.com/products/{ASSET}-USD/candles?granularity=3600

Hourly close history shows up to 24 recent returned candles. Missing intervals are not interpolated. Thresholds are personal monitoring settings, not calibrated risk scores. This workspace does not classify people, accounts, or transactions as fraudulent.

Refresh & provenance

Market statistics refresh on opening, on demand, and once per minute while this tab is visible. Each asset retains its own retrieval timestamp. A failed request preserves the last available value and marks it stale.

If a live request fails before any refresh succeeds, the app uses the bundled public-data snapshot, visibly labeled with its original retrieval time. It never substitutes fabricated prices.

Working boundaries

SignalDesk is a personal research and monitoring tool. It does not execute orders or provide investment recommendations. Alerts and notes are local to your browser, and monitoring pauses when the app is closed.

A reviewed signal stays in the inbox while its rule remains breached. New observations are compared against saved thresholds on refresh.
